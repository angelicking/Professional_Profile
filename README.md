# Luis Garcia — Program Manager

Personal site for Luis Garcia, PMP. Next.js, with a career Digital Twin chat via OpenRouter.

## Local

```bash
npm install
npx next dev
```

Open [http://localhost:3000](http://localhost:3000).

For the twin, add `OPENROUTER_API_KEY` to `.env` in the project root. The key is server-only and is not committed.
